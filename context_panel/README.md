# JevClean

通过 CDP 在 Codex / ChatGPT 桌面端挂载右侧上下文整理面板。Python 标准库提供本地服务，Node.js 22 提供 CDP 桥；无第三方安装依赖。

## 启动

首次打开后可点击顶部 API Key 配置。也支持 `AI_GATEWAY_API_KEY` 环境变量，或明确指定环境文件：

```sh
python3 -m context_panel.launch --env-file /absolute/path/to/your.env
```

macOS 也可以双击仓库中的 `启动Jev侧栏.command`。启动器支持 `JEV_ENV_FILE`，不内置个人环境文件路径。

启动器会复用 8766 本地服务；若没有 9231 CDP listener，尝试打开独立调试窗口，不关闭原窗口。注入后保持终端运行；Ctrl+C 卸载侧栏。原窗口未启用 CDP 时不能热注入。应用完整刷新或升级后可能需要重新连接；先退出旧桥进程再运行启动器。

独立浏览器视图：

```sh
python3 -m context_panel.launch --browser
```

## 使用

嵌入模式的入口位于 Codex 左侧导航「探索」下方，点击「JevClean」打开或收起。面板标题栏可拖动，位置保存在本机；「复位」恢复默认位置，「×」收起面板。没有悬浮入口。

1. 默认显示最近聊过的 3 个未归档会话，使用 Codex 显示的任务名，不展示内部子代理记录。点击搜索框或输入 `@` 弹出候选；支持标题片段、项目、ID 和会话链接。多个关键词用空格隔开，命中任意一个即可，命中更多关键词优先，相关性相同时按最近对话时间排序。搜索最多展示 8 个候选，范围不限于最近 3 个会话；支持方向键、回车和 Escape。
2. 点击最近对话或搜索候选后，本机先统计消息数、段落数、字符数、自动保留段落和预计 Jev 请求批次；此时不调用模型。点「一键整理」使用同一份快照（有效期 5 分钟，可刷新）。整理规则统一从单一提示词读取；配置改变后须重新统计。默认包含用户消息和助手最终回复，工具记录单独计数。
3. 默认两类：左侧消息流中的段落按真实结果飞入「保留／省略」桶；开启「手动复核」才显示第三个「待复核」桶。数量与柱条同步展示实际结果。超长段落及关闭用户消息判断时的用户消息直接归入保留，动画不是模型推断过程。可关闭动画；「回放归类」只播放已得到的结果，不重新调用模型。
4. 点击分类桶筛选并打开逐条复核。可手动改变分类；超过 6000 字符的完整段落锁定保留；关闭用户消息判断时用户原话也锁定保留。界面先显示200条，更多记录可继续加载；导出包含全部保留记录。
5. 点击「预览并应用…」（手动复核模式为「复核并应用…」）查看省略段落、字符变化和完整精简稿，再点「确认应用为精简副本」。确认后才能下载、复制或预填同项目的新任务，不会自动发送。Apply 保存带修订号的 `.applied.md` 副本，不删除原始 JSONL，不替换当前活跃上下文；待复核内容全部保留。手动调整分类后，应用确认失效，须重新复核。
6. 一个「整理提示词」输入框描述整体规则，无需占位符；「保留标准」「省略标准」单独配置，开启手动复核时另显示「待复核标准」。省略阈值、批次大小、并发批数和手动复核仍是独立参数。保存后下一次整理生效；正在运行的任务使用独立配置快照。恢复默认要点击保存才生效。

## 外观皮肤

右上角「外观」与「提示词设置」分开。提供炫彩（紫粉渐变）、清新（薄荷浅色，默认）、科技（深蓝电光青）、朴素（暖白石墨）四套皮肤。点击立即切换并自动保存；面板、分类桶、统计条、弹窗和拖动标题栏同步适配。

外观通过 `/api/appearance` 单独保存在本机数据目录的 `appearance.json`，重开面板仍生效；不进入模型请求，不修改提示词、运行配置或已统计的快照。保存失败会恢复上一次皮肤并显示原因。

## 数据与边界

- Codex 数据只读。按 `history_base` 递归重建共享历史，同时验证字节和 ordinal 截止边界；不把父任务 fork 后的新记录混入。
- 输出默认在 `~/Library/Application Support/JevContext/`，包含设置、运行 JSON 与 Markdown。应用更新与代码目录变更不会删除配置。
- API Key 可在独立配置窗口输入，提交给本地 Python 服务保存；只返回配置状态，不回显已保存的 Key。本地 API 有临时访问令牌，CDP 桥限定执行上下文及每次连接的随机能力凭证。
- 本地输出剔除识别到的秘密但保留文件路径；出站 Jev 文本额外匿名化用户主目录。自动脱敏不是敏感信息完整识别保证，业务材料是否可外发由使用者决定。
- Jev 每批看到各目标的相邻上下文窗口，默认每个窗口为前一段、目标段、后一段；重叠窗口去重，不附加全文或最近五条用户消息。默认只请求 keep/drop 两类，信息不足或省略概率低于门槛自动保留；开启手动复核时才请求第三类并将这些内容放入待复核。提示词可调，但需要在代表性数据上验证删除质量。
- 结果为抽取式精简副本，不是生成式摘要；待复核和未处理片段保留。不会手改 JSONL、数据库或加密压缩项，不会替换正在运行的上下文。
- 默认每批5段、最多2批并发，可配置每批1–8段、并发1–4批。HTTP 502/503/504 会将失败批次放回队尾，其他就绪批次继续；同一批最多重试 2 次，分别至少等待 1 秒和 2 秒，等待不占用并发名额。重试用完仅保留该批内容，其他批次继续完成，整轮标记为部分失败。非暂时性错误（如 400/401 或无效分类结果）仍停止调度新批次。点击停止也取消待重试队列；已发出的请求会完成并可能产生用量。失败批次不会应用部分判定；关闭复核时自动保留，开启时转待复核。
- 当前集成使用 CDP 和已核实的内部导航消息，不是稳定的官方 UI 插件 API。升级可能影响挂载或预填；独立浏览器版本仍可使用。

## 开发与验证

```sh
python3 -m unittest context_panel.test_core context_panel.test_workflow -v
python3 -m context_panel.server --env-file /absolute/path/to/your.env
node context_panel/cdp.mjs --cdp http://127.0.0.1:9231
```

`core.py` 负责历史重建、脱敏、Jev请求和保守判断；`server.py` 负责配置、作业与真实事件流；`cdp.mjs` 负责隔离 iframe 与本地通信桥；`web/` 是页面。

本地浏览器使用带鉴权的 fetch SSE。嵌入侧栏通过 CDP 桥按事件序号等待增量事件，服务端有新事件即返回，最多等1秒再重连；不再固定间隔400毫秒。界面合并一批事件的重画，未展开明细不生成段落卡片，瀑布流复用未变化的节点。

预览只对用户选中的会话读取正文，列表搜索仍只读会话元数据。服务失败或停止后，尚未得到结果的段落自动保留（手动复核开启时进入待复核）；页面显示中断状态，不显示为成功。后台窗口暂停展示动画，保留真实分类统计。


手动复核默认关闭，设置对下一次整理生效；运行中的任务及历史报告保留创建时的模式。关闭后不是隐藏待复核队列：模型请求本身只有两类，低把握和未完成内容的最终状态均为 keep。两种模式都保留 Apply 确认。请求数统计已发起的批次（含失败请求），token 只统计供应方返回的用量。

503 重试在界面显示等待批数、已重试次数和最终未成功批数。请求数含重试尝试；每条批次记录包含原始批号、请求序号、尝试次数、耗时及 HTTP 状态。全部恢复成功时整轮正常完成，不残留已恢复的错误提示。


## 中英文界面与产品名称

产品名称为 **JevClean**。顶部 `EN / 中文` 按钮即时切换系统界面，并自动保存语言偏好；与皮肤共用独立外观配置，局部更新不会覆盖另一项设置。覆盖选择会话、统计、分类动画、复核、重试、错误、确认弹窗、提示词设置标签及交接提示。

对话标题、正文、项目路径、自定义提示词保持原文。内置默认提示词提供两种语言，设置表单按当前语言展示默认值；只有点击保存才改变整理配置。Markdown 导出的标题和说明按当前界面语言生成，保留内容不翻译，Apply 的修订校验不变。

`web/i18n.js` 是集中维护的中英文文案表。动态文案通过 `tr()` 填入参数；后端固定原因通过 `systemText()` 翻译，不能将对话原文传入此函数。静态文本只在初始模板中注册，不扫描翻译用户内容。

更新后双击仓库根目录的 `重新加载Jev侧栏.command`，或运行 `python3 -m context_panel.launch --reload --env-file /absolute/path/to/your.env`。它只重启 Jev 本地服务与桥接进程，不结束 Codex；如果 Jev 正在整理，会拒绝重载，避免中断请求。

独立界面回归：配置提供 Playwright 的 `NODE_PATH`，运行 `node context_panel/test_ui.mjs`。测试使用独立无头浏览器和模拟接口，不接触 Codex 窗口，不发送真实模型请求。


## User-message classification

The bilingual Prompts setting `Classify user messages` is enabled by default, including migration from settings without this field. Disable it to protect user messages. Complete segments over 6000 characters remain protected in either mode. Changing this setting invalidates the preview; existing runs and reports retain their original snapshot.

Compact output is Markdown supplied as the body of one new user message. It does not replace the native Codex message sequence. User-only or assistant-only excerpts are valid text copies; users should still check for missing questions, constraints, or references that make an answer meaningful.


## 单一整理提示词

整体提示词配置为 `prompt`，分类标准独立保存为 `criteria.keep/drop/review`。请求的 `state.instructions` 使用提示词文本，`state.segments` 附上各目标窗口里的段落（编号、角色、正文），`state.windows` 列明每个目标对应的前后文编号。每段 `questions`、编号和分类字段名由程序生成，各选项说明直接读取 `criteria` 参数，不解析提示词中的标题；不再额外附加最近五条用户消息，也不发送全文。

旧设置的默认提示词迁移为对应语言的新默认值；自定义目标、规则和逐段要求合并到整体提示词，旧编号占位符替换为“当前段落”，原有 `criteria` 单独保留。过渡版本只存了 `prompt` 而没有 `criteria` 的配置会补上默认分类标准，保留提示词原文，不按标题猜测拆分。迁移在读取时执行，保存时写入新格式，历史报告保持不变。

## 相邻上下文窗口

`context_window_size` 默认 3，即前一段＋目标段＋后一段，支持 1–21 的奇数。5 表示前后各两段，1 表示仅目标段；对话首尾不足时只提供实际邻居。这是抽取后的段落数量，不是对话轮数，也不是字符数或 token 上限。

窗口按原始顺序计算，跨请求批次，自动保留的段落也可以作为邻居证据。一个批次发送多个目标窗口的并集，重叠正文只传一次；每个目标明确关联自己的窗口，只有目标出现在 `questions` 中。窗口之外的完成记录不可见，所以无法保证识别远距离的取代关系。修改窗口使旧预览失效，正在运行的任务和历史报告保持原配置。

部署完成、需求验收、过期过程记录等具体取舍由用户在可见的分类标准中配置，不内置为额外过滤策略。整体默认提示词只说明按分类标准和相邻证据判断，保留原有通用分类默认值；不会覆盖已保存的自定义配置。

## API Key 配置

面板顶部的 **API Key** 打开独立配置窗口。填写自己在 Vercel AI Gateway 创建的 Key，保存后再点击“一键整理”。未配置时点击整理会打开此窗口并提示先配置，服务端也会拦截，不发送分类请求。已配置只代表存在凭据，不代表已验证有效性或余额。

凭据单独保存在数据目录的 `credentials.json`（默认 `~/Library/Application Support/JevContext/credentials.json`），以 0600 权限创建，不进入提示词设置、报告或前端存储；API 只返回配置状态。文件未加密。面板保存的 Key 优先于 `AI_GATEWAY_API_KEY` 环境变量及启动器指定的环境文件；没有面板凭据时沿用原配置。新 Key 用于后续整理，当前请求继续使用启动时读取的 Key。更换会使旧预览失效，页面自动重新统计。

分发源码时不包含本机数据目录、环境文件、访问令牌或凭据。其他用户各自在面板配置自己的 Key。

## 正则跳过

提示词设置中单独显示 `skip_patterns`，每行一条 Python 正则，忽略大小写、任一命中即跳过。新配置及缺少该字段的旧配置使用显式默认 `key`、`apikey`；清空保存为 `[]` 可关闭，已有自定义规则保持不变。默认包含匹配，`API_KEY`、`apikey`、`keyboard` 都命中；需要更窄范围时可自行使用边界或字段格式规则。

在脱敏和分段前匹配整条抽取消息。命中消息的所有段落自动保留并标明原因，不进入判断问题，也不进入其他段落的相邻上下文；窗口仍按原有位置计算，移除命中邻居后不补入更远消息。原有脱敏仍生效，跳过不代表原始密钥会进入导出稿。预览显示跳过的消息和段落数，请求数量按实际待判断段落计算。包括工具输出时同样应用此规则。

最多 20 条规则，每条最多 500 字符；错误正则不能保存。匹配在独立本地进程中批量运行，3 秒超时则停止本次预览并提示修改，不发起模型请求。修改规则后须刷新快照，页面保存时自动刷新；历史结果和运行中的任务保留原配置。
